# MotionPen
Motionpen is a computer vision project that lets you **draw in the air using your finger**, tracked in real-time with **OpenCV and MediaPipe** through a webcam.

### Gesture Controls
- **Thumb + Index** → Write / Draw
- **Thumb + Middle** → Erase
- **Thumb + Pinky** → Clear screen
